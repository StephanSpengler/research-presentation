Control State Reachability


Show: RDMA state reachability is undecidable
Idea: use RDMA buffers to simulate a perfect message channel
  • ensure exactly-once delivery (prevent message loss and duplication)
  • reduction from PCP
    (Post's Correspondence Problem)
  • synchronisation not needed
    (rfence, poll)

Robustness

y := w
z := x
x := 2
RDMA: R(w, 1) W(x, 2) R(x, 2) W(z, 2) W(y, 1)

SC: R(w, 1) W(y, 1) R(x, 0) W(z, 0) W(x, 2)

  • prevent / detect unexpected behaviour
  • focus on observable behaviour
    • values of read/write operations
    • order of write operations (per variable)

Normal Form Construction

  • requirement: minimal violation
    R(w, 1) W(x, 2) R(x, 2) W(z, 2) W(y, 1)
  • identify and remove maximal event
    R(w, 1) W(x, 2) R(x, 2) W(z, 2) W(y, 1)
  • order in a sequentially consistent way
    R(w, 1) W(y, 1) R(x, 0) W(z, 0)
  • reinsert maximal event
    R(w, 1) W(x, 2) W(y, 1) R(x, 2) W(z, 2)

Normal Form Structure

R(w, 1) W(x, 2) R(x, 2) W(z, 2) W(y, 1) R(w, 1) W(x, 2) W(y, 1) R(x, 2) W(z, 2)

  • ⟨SC-consistent events⟩ ⟨maximal event⟩ ⟨SC-consistent events⟩
  • structured violation witness
  • greatly reduces search complexity

Complexity Bounds


Theorem:
RDMA-robustness is ExpSpace-complete in the general case.


Theorem:
RDMA-robustness for programs without poll operations
is PSpace-complete.
